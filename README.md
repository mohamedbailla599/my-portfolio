## What's inside

- **Skills** — technologies and concepts I have used or studied
- **Education & experience** — my academic background and practical experience
- **Contact** — ways to connect with me

## Built with

- Next.js
- React
- TypeScript
- Tailwind CSS

## Run locally

Requirements: Node.js and pnpm.

```bash
git clone https://github.com/mohamedbailla599/my-portfolio.git
cd my-portfolio
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
